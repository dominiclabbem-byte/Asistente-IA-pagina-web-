Como integrar el asistente en tu sitio

Pega este snippet justo antes de cerrar el tag </body> en tu sitio web:

<!-- BestFood Chile - Asistente IA -->
<script>
  // URL de tu servidor backend
  window.BESTFOOD_API_URL = 'https://tu-servidor.com/api/chat';
</script>
<script src="https://tu-servidor.com/static/chat-embed.js"></script>

Para levantar el servidor backend en local o en un VPS:

# 1. Instalar dependencias
pip install -r requirements.txt

# 2. Configurar variables de entorno
cp .env.example .env
# Edita .env y agrega tu ANTHROPIC_API_KEY

# 3. Iniciar servidor
uvicorn server:app --host 0.0.0.0 --port 8000
